# S18 — cancellable project packages

The existing project ZIP import/export worker now accepts cancellation and settles once. Success, failure, timeout, explicit cancellation and application unmount all release the native worker and abort listener. Queued replies after cancellation cannot import a project, download a file, or replace progress. The UI provides a visible cancellation button and distinguishes an intentional stop from an error. A synchronous controller guard prevents overlapping operations, and the hidden input remains disabled until client data is ready. Normal in-app navigation retains the ongoing operation. A browser-native file read may finish before an early cancellation is observed, but the aborted signal prevents starting a worker or admitting its result.
