# S13 — bounded workspace backup and additive recovery

Settings now exports a selected set of complete projects in one ZIP and previews validated imports before changing the workspace. Existing identities are copied independently; originals, immutable delivery/file history, reviews, drafts and archived state remain intact. Workspace identity/name is preserved. Search and eight-project pages keep the selector usable at the 100-project limit. A failed IndexedDB commit leaves one recoverable in-memory import, disables duplicate submission and permits downloading that current session before reload.

The package holds a strict manifest and individually importable project ZIPs. SHA-256 and all inner project references are verified. Limits apply before transfer, to logical files/metadata, to the outer expansion, and to the total inner expansion before decompression. A forged nested ZIP advertising 121 MB is rejected before allocating its contents. Background workers terminate after success, failure, cancellation and route changes, with a two-minute deadline. Nothing is silently truncated or deleted.

Executed: seven domain fixtures, all workspace typechecks, 276 unit tests in 42 files at integration, Studio production build and all 99 Studio browser flows (5.1 minutes, Chromium/Firefox/WebKit). The five new flows per browser cover additive recovery, actual quota failure, corrupt packages, cancellation/navigation cleanup, paginated selection and two real incompressible files totaling 12.2 MB. Exact originals survive import, actual IndexedDB reload and a second export. The large-file gate was also rerun in all three browsers with a real filesystem upload, avoiding Playwright's own base64 FilePayload construction on the page; all three passed. Chromium's measured application long tasks in that run were 50, 95 and 51 ms, and both actual workers were terminated. This is a measurement on this fixture, not a universal performance guarantee.

Twenty-one new axe scans passed with zero violations. The new settings coverage found and fixed several pre-existing low-contrast budget/integration labels. Desktop, tablet and mobile backup/restore screenshots were visually inspected. Evidence: `reports/studio/*workspace*`, `reports/studio/a11y/*workspace*`, `reports/e2e-results.json`, `tests/e2e/studio-workspace-backup.spec.ts` and `docs/studio-workspace-backup.md`.
